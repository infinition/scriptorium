Scriptorium.

Votre compagnon d'écriture.

Un éditeur Markdown sans distraction qui lit et écrit des fichiers `.md` ordinaires sur votre propre disque. Titres, listes, code et formules s'affichent en direct, rien ne quitte votre machine.

Ce que Scriptorium sait faire

Vos fichiers, votre disque

Chaque document est un fichier `.md` ordinaire. Une section est un dossier. Scriptorium reflète votre espace de travail, il ne le verrouille pas.

Rendu en direct

Markdown, LaTeX, code coloré, tableaux et callouts s'affichent en direct. La ligne que vous éditez repasse en source brut.

Idées

Un nuage de phrases classé par thème. Cliquez pour archiver, clic droit pour insérer dans le texte.

Instantanés

Un historique de révision par document. Comparez, restaurez, revenez en arrière avant une coupe.

Sans distraction

Mode focus, machine à écrire, focus paragraphe, lecture continue. L'interface s'efface devant le texte.

Hors ligne

Aucun CDN, aucune dépendance réseau pour l'édition. Tout est servi depuis votre machine.

Recherche plein texte

Recherchez dans les titres, le contenu des documents et les idées, en une frappe (`Ctrl+P`).

Bilingue

Français et anglais, avec un guide complet intégré aux documents de démo.
